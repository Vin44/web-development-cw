Validation & Page Analysis

Team page

The Our Team page introduces the members who contributed to developing the “Life Below Water” website. It highlights each team member’s role and responsibilities in the project while maintaining a clean and organized layout. The page helps users understand the collaboration behind the website and recognize individual contributions.

Key Features

  • Team member cards displaying names, roles, and contributions
  • Clean and structured layout for easy readability
  • Keyboard accessibility using tabindex="0" for interactive elements
  • Responsive design that adjusts to different screen sizes

HTML Validation

The Our Team page HTML was validated using the W3C Markup Validator. The page follows proper HTML5 structure with correctly nested elements and semantic tags. No major validation errors were found.

CSS Validation

The CSS for the Our Team page was validated successfully. Styling rules were written with correct syntax, ensuring a consistent layout, proper spacing, and responsiveness across devices.

Feedback page

The Feedback page allows users to share their opinions and experiences about the “Life Below Water” website and its programs. It also displays ratings and reviews from participants, helping visitors understand the impact of different initiatives. This page encourages user interaction and helps improve the website through collected feedback.

Key Features

  • Display of available ocean conservation programs with action buttons
  • Ratings and reviews section showing user experiences and scores
  • Overall rating summary based on user reviews
  • Feedback form for users to submit comments and suggestions
