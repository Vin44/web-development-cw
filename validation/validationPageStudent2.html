Validation & Page Analysis

Splash Screen

The Splash Screen serves as the initial entry point of the website, providing users with an engaging introduction to the “Life Below Water” theme. It visually presents the branding and automatically redirects users to the main home page after a short duration.

Key Features

  • Animated introduction screen using CSS effects
  • Automatic redirection implemented with JavaScript
  • Consistent theme design with logo and colors
  • Responsive layout for different screen sizes

HTML Validation

The Splash Screen HTML was validated using the W3C Markup Validator. The page follows correct HTML5 structure with properly nested elements. No critical errors were found.

CSS Validation

The CSS used for the Splash Screen was validated successfully. Animations and styling follow correct syntax, ensuring smooth visual effects and responsiveness across devices.

Action Impact Simulator

The Action Impact Simulator is an interactive feature that allows users to explore how different human activities affect marine ecosystems. Users can select actions and instantly view their environmental impact, helping to raise awareness about ocean conservation.

Key Features

  • Interactive user inputs (buttons and selections)
  • Dynamic updates using JavaScript
  • Real-time feedback based on user choices
  • Engaging and user-friendly interface

HTML Validation & CSS

Since the simulator page contains internal CSS, W#C Nu HTML checker checked both HTML & CSS in one page. The Simulator page HTML was validated using W3C standards and follows proper HTML5 structure. Semantic elements and correct nesting ensure accessibility and maintainability. And also CSS for the Simulator page was also validated and includes layout styling, transitions, and responsive design. All styles follow correct syntax with no major issues.

Content Page (Student 2)

This content page focuses on the importance of protecting life below water by highlighting ocean threats, solutions, and the positive impact of conservation efforts. The page is structured into clear sections to improve readability and user navigation.

Key Features

  • Quick navigation bar with anchor links for smooth scrolling
  • Well-organized sections (Introduction, Threats, Solutions, Impact, Conclusion)
  • Use of images and video to enhance user engagement
  • Sticky navigation bar for improved usability

HTML & CSS Validation

Since the simulator page contains internal CSS, W#C Nu HTML checker checked both HTML & CSS in one page. The Content Page HTML was validated using the W3C Markup Validator. The page follows proper HTML5 structure, including semantic elements such as header, nav, main, section, and footer. All elements are correctly nested and no validation errors were found. And also the CSS for this page was validated using the W3C CSS Validator. The styling includes layout design, typography, hover effects, and responsive adjustments. All CSS rules follow correct syntax, ensuring consistency and readability across different devices.
